# Editing the lab-life collage

In the editor, open Life in the lab, choose an existing Photo to add entry, and upload a Photo. Set Caption, Photo credit and Image description. Use Wide photo for two columns or Photo shape: portrait for a tall frame. Sort order controls placement; the first item is the large featured photo. Crop focus defaults to 50% 50%; try 50% 25% to keep faces near the top. Blank photo fields show the requested placeholder spaces. Create more entries to extend the collage. These are layout placeholders, not records of real events.

The editor link is removed from visitor navigation and the footer. The /admin/ route still exists and requires its configured editing backend for hosted changes; hiding its link is not access control. Online editing remains disabled until backend authentication is configured.
